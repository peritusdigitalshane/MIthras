# Mithras Threat Defence

**Enterprise-grade endpoint security, built for the realities of small Australian businesses.**

---

### The problem

Small businesses live with a security gap that the big players can't or won't solve:

- They run mixed fleets — modern Windows 11 alongside Windows 7 / Server 2012 workstations they can't migrate
- They can't afford a full SOC team, but their compliance and insurance auditors expect 24/7 monitoring
- CrowdStrike, SentinelOne, and Huntress start at $8–$15 per seat *before* the per-tenant minimums that price out an 8-seat client
- Off-the-shelf RMM tools watch uptime — not Defender state, threats, vulnerabilities, or M365 identity

### What Mithras does

Mithras turns the Windows Defender already installed on every endpoint into a **managed SOC platform**, then layers on the modern stack a real MSP needs:

| Capability | What it means in practice |
|---|---|
| **Defender as EDR** | Real-time policy push, threat ingest, posture monitoring — no second agent to deploy. |
| **EOL Windows hardening** | Best-effort security controls for Windows 7 / Server 2008/2012 boxes that CrowdStrike refuses to support. The differentiator no one else has. |
| **M365 ITDR** | Identity threat detection: risky sign-ins, mailbox-rule injection, OAuth grant abuse — all surfaced in one console. |
| **AI SOC triage + investigation** | Every alert is auto-triaged by an LLM with citation-enforced reasoning. Operator gets a 2-line "what happened, what to do" instead of a JSON wall. |
| **Vulnerability scanning** | Software inventory + CVE matching, mitigation suggestions written by AI. |
| **Remote desktop via MeshCentral** | Embedded RMM — one click from any endpoint to a remote session, no Chrome extensions, no separate portal. |
| **Microsegmentation + app whitelisting** | Per-endpoint firewall + WDAC policy via PowerShell or Group Policy. |
| **24/7 SOC dashboard** | Grafana-powered, SSO from the platform — your customer's posture in one panel. |
