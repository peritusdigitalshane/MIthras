# Mithras Channel Sales Kit

Everything a distributor's sales team needs to pitch and close Mithras.
Markdown drafts here; polished PDFs/PPTX live in Supabase Storage and are
linked from `/distributor/resources` inside the platform.

| Asset | File | Purpose | Status |
|---|---|---|---|
| One-pager | `one-pager.md` | 1-page glanceable handout. Print or attach. | v1 draft |
| Pitch deck | `pitch-deck.md` | 10-slide outline for the sales rep to convert to Keynote/Google Slides. | v1 draft |
| Demo script | `demo-script.md` | 15-minute guided product demo with talking points. | v1 draft |
| Pricing sheet | `pricing-sheet.md` | Distributor + reseller + retail pricing with margin worked examples. | v1 draft |
| Battle cards | `battle-cards.md` | One card per competitor (CrowdStrike, Huntress, Avanan, Acronis, Sophos). | v1 draft |
| Brand kit | `brand-kit.md` | Logo usage, colour palette, voice + tone, naming rules. | v1 draft |
| Reseller onboarding | `reseller-onboarding.md` | First-week playbook for a new reseller signed up by a disty. | v1 draft |

## Editing notes

These are first drafts. Shane will edit them in his voice — keep the technical
accuracy bar high but feel free to rewrite tone, examples, and Australian
spelling/idiom as the platform's voice solidifies. Don't add competitor claims
that aren't verifiable; channel reps quote these word-for-word.

## What to ship as PDFs

The one-pager, battle cards, and pricing sheet should ship as branded PDFs —
they get printed, emailed, and dropped into RFPs.

The pitch deck stays as a Keynote/Google Slides source-of-truth; PDFs are
secondary.

The demo script stays in the portal — sales reps follow it on-screen during a
live demo.
