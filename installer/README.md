# Mithras Threat Defence — Installer

Builds `MithrasAgent-Setup-{version}.exe` from the agent runtime in
`../agent/runtime-powershell/`. Compiled with Inno Setup 6.

## Setup (one-time)

1. Install Inno Setup 6 from <https://jrsoftware.org/isdl.php> (free, ~3 MB).
   Default install path is auto-detected by `build.ps1`.

That's it. No other dependencies.

## Build

From this directory:

```powershell
.\build.ps1
```

Outputs `output/MithrasAgent-Setup-{version}.exe`. The version is read from
`../agent/runtime-powershell/agent.version`.

## What the installer does

| Step | What happens |
|------|-------------|
| 1 | Customer double-clicks the `.exe` → Windows shows a UAC prompt (yellow "Unknown publisher" until you sign — see below). |
| 2 | Welcome screen with Mithras brand banner. |
| 3 | License agreement (`eula.txt`). |
| 4 | Enrolment code prompt (skipped if the customer launched with `/CODE=xxx`). |
| 5 | Ready to install. |
| 6 | Silent execution of `install-agent.ps1` with the customer's API URL + enrolment code. |
| 7 | Finish screen with an optional "Open Mithras portal" checkbox. |
| 8 | Add/Remove Programs entry: `Mithras Threat Defence` · Publisher: `Peritus Digital Pty Ltd` · with shield icon. |
| 9 | Clean uninstall via `unins000.exe` calls `uninstall-agent.ps1`. |

## Silent install (for MSPs / RMM tools)

```powershell
MithrasAgent-Setup-0.7.13.exe /SILENT /CODE=YOUR-ENROL-CODE
```

`/SILENT` shows only a progress bar; `/VERYSILENT` shows nothing. The `/CODE`
flag pre-fills the enrolment field and skips the code-entry page.

## Silent uninstall

```powershell
"C:\Program Files\Mithras\unins000.exe" /SILENT
```

## Customer experience without a code-signing cert

Until you buy a code-signing certificate, customers will see a yellow
SmartScreen warning that says **"Windows protected your PC — Unknown publisher"**
the first time they run the installer. They click `More info → Run anyway` and
the install proceeds. The UAC prompt will also show the publisher field in
yellow as "Unknown."

Everything else looks identical to a signed installer. SmartScreen will
silently allow installs once enough customers have run it successfully
(unofficial threshold: ~3,000 installs across enough distinct machines).

## Adding code signing later

Buy any standard or EV code-signing certificate (e.g. Certum OV ~$120/yr,
DigiCert EV ~$600/yr). Then add a step to `build.ps1` after `ISCC.exe` runs:

```powershell
signtool sign /tr http://timestamp.digicert.com /td sha256 /fd sha256 /a `
  "$($installer.FullName)"
```

For cloud-HSM signing (DigiCert KeyLocker, SSL.com eSigner, Certum
SimplySign), follow the CA's wrapper instructions — the `signtool` flags
change to point at the HSM CSP.

Nothing in the installer itself changes. The cert just adds a signature
stapled onto the `.exe`.

## Customising the banners

The default banners are auto-generated by `build.ps1` (Mithras navy→indigo
gradient + amber shield + wordmark). To use custom artwork, replace
`assets/wizard-banner.bmp` (164×314, 24-bit BMP) and
`assets/wizard-small.bmp` (55×58, 24-bit BMP), then build with
`.\build.ps1 -SkipAssetGen` so they don't get overwritten.
